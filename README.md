# Інтерактивна лекція: «Сучасна криптографія: магія цифр, яка захищає твої секрети»

Проєкт складається з **двох взаємопов'язаних веб-додатків** українською мовою:

1. **[`index.html`](./index.html) — Презентація та інтерактивні демо для екрану/проектора** (очищена від вікових плашок та таймера):
   - **Демо №1: Лабораторія шифрів** — Український Шифр Цезаря з миттєвим Brute-Force перебором усіх 32 ключів проти справжнього **AES-256-GCM** (через браузерний Web Crypto API).
   - **Демо №2: Обмін ключами Діффі-Геллмана та Месенджери E2EE** — Візуальний симулятор змішування кольорів та порівняння хмарних чатів (звичайний Telegram / Discord) із наскрізним шифруванням E2EE (Signal / WhatsApp / Secret Chat).
   - **Демо №3: Хеш-машина SHA-256 та Краш-тест паролів** — Живе порівняння лавинного ефекту SHA-256 із підсвічуванням змінених символів та калькулятор часу злому паролів (словникові атаки vs Passphrase з 4 слів).
   - **Демо №4: Вікторина з залом «Фішинг чи Оригінал за 10 секунд»** — 4 реалістичні кейси (Instagram `rn`/`m`, викрадення сесій Telegram через «голосування», Monobank Банка, омографи Steam).

2. **[`speaker.html`](./speaker.html) — Кабінет Спікера (Повна версія з теорією, графіками, схемами та нотатками)**:
   - Повний дослівний текст виступу до кожного блоку;
   - Глибока теоретична довідка (Тріада CIA, математика 14 раундів AES-256-GCM, дискретний логарифм у Діффі-Геллмані, властивості SHA-256 та формула ентропії Шеннона);
   - Вбудовані векторні архітектурні ілюстрації (SVG-схеми перехоплення пакетів у Wi-Fi, порівняння архітектури Хмарного чату та E2EE, конвеєр AES-256, схема Reverse Proxy фішингу проти FIDO2 Passkeys);
   - Наочні графіки експоненціального росту простору ключів та часу перебору паролів на GPU-кластерах;
   - Готові відповіді на типові запитання із залу (квантові комп'ютери, безпека менеджерів паролів, VPN тощо) та підтримка друку в PDF.

## Як запустити
Обидві версії працюють повністю автономно без Інтернету:
- Відкрийте [`index.html`](./index.html) для показу слайдів і демо або [`speaker.html`](./speaker.html) для підготовки та читання з другого екрана/планшета.
- Між обома сторінками є пряма кнопка переходу у верхній панелі (`📚 Кабінет спікера` ↔ `🖥️ Відкрити Презентацію та Демо`).


## Публікація на GitHub Pages

Проєкт повністю готовий до розміщення на **GitHub Pages** (усі шляхи відносні, додано `.nojekyll` та автоматичний workflow `.github/workflows/deploy-pages.yml`). Крім того, GitHub Pages працює через `https://`, що забезпечує роботу браузерного `Web Crypto API` (`crypto.subtle`) на всіх пристроях.

### Варіант А — Через гілку (найпростіший)
1. Завантажте репозиторій на GitHub:
   ```bash
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/<ВАШ_ЛОГІН>/<НАЗВА_РЕПО>.git
   git push -u origin main
   ```
2. На GitHub відкрийте **Settings → Pages**.
3. У розділі **Build and deployment → Source** оберіть **Deploy from a branch**, вкажіть гілку `main` та папку `/ (root)`, і натисніть **Save**.

### Варіант Б — Через GitHub Actions (автоматично)
1. У **Settings → Pages → Source** оберіть **GitHub Actions**.
2. Файл `.github/workflows/deploy-pages.yml` автоматично опублікує сайт при кожному `git push` у гілку `main`.
